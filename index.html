什么是字典序？

像查字典一样，从左到右比较。对于 n 个不同元素，共有 n! 个排列；排序后的 0-based 编号就是字典序值。

01 / RANK

朴素康托展开

O(n²)

每个位置扫描右侧元素。阶乘表占 O(n) 空间；除阶乘表外，计算过程只用常数额外变量。

rank += smaller × (n − i − 1)!
02 / NEXT

下一排列

O(n)

最多扫描两次后缀，再原地反转。额外空间为 O(1)，不会生成所有排列。

pivot → swap → reverse
FURTHER / OPTIONAL

树状数组优化

O(n log n)

用 Fenwick Tree 快速查询“已出现元素中更小的数量”。适合更大 n，但不是本次课堂理解重点。

query(value − 1)
